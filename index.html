نصب در سه قدم

یک بار نصب، بعد کافی است به فارسی بپرسید.

01

uv را نصب کنید

ابزار اجرای بسته‌های پایتون؛ یک دستور، یک‌بار برای همیشه.

pip install uv
02

دستور سرور را بچسبانید

هر کارت یک دستور uvx دارد؛ همان را در تنظیمات برنامهٔ خود قرار دهید.

uvx digikala-mcp
03

در برنامه وصل کنید

از دکمهٔ «ساخت تنظیمات» فایل آمادهٔ Claude Desktop، Claude Code، Cursor یا VS Code را بگیرید.

claude_desktop_config.json
